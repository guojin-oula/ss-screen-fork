# 总览与使用规则

本目录回答四个问题：工作区里有什么、重要文件在哪里、应该按什么顺序阅读、文件变化后怎样同步导航。

## 文件说明

| 文件 | 作用 |
|---|---|
| [`工作区目录树.md`](工作区目录树.md) | 带注释的真实目录结构，排除缓存、虚拟环境和 Git 内部文件 |
| [`文件资产总索引.md`](文件资产总索引.md) | 按功能列出正式源码、测试、文档、资料和自动化入口 |
| [`推荐阅读路径.md`](推荐阅读路径.md) | 按学习目标和开发任务给出阅读顺序 |
| [`ZMD同步更新规则.md`](ZMD同步更新规则.md) | 规定新增、修改、删除、移动后的同步动作和检查清单 |

## 推荐顺序

1. 先读 [ZMD 总入口](../README.md)。
2. 浏览 [`工作区目录树.md`](工作区目录树.md) 建立空间认识。
3. 使用 [`文件资产总索引.md`](文件资产总索引.md) 定位具体文件。
4. 按 [`推荐阅读路径.md`](推荐阅读路径.md) 学习或执行任务。
5. 工作结束前执行 [`ZMD同步更新规则.md`](ZMD同步更新规则.md)。
