# Band screening workflows

VASP and ABACUS PBE/HSE06/mBJ launch, recovery, k-path, analysis, and export flows.

**Current package coverage:** The package provides external gap file contracts but not native DFT execution.

**Historical cautions:** Names, method labels, node IDs, resources, queues, and concurrency are historically site-specific.

Notebook outputs and execution state are preserved. External datasets and calculation artifacts referenced by these files are not included.
