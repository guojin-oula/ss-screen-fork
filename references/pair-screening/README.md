# Pair screening

MP/WBM loading, valence filtering, structure grouping, gap feedback, and pair enumeration.

**Current package coverage:** Core behavior is largely migrated to `src/ssscreen/data` and `src/ssscreen/pair`.

**Historical cautions:** Historical files include the `__getitem___` typo, stale ternary logic, and legacy schema spellings.

Notebook outputs and execution state are preserved. External datasets and calculation artifacts referenced by these files are not included.
