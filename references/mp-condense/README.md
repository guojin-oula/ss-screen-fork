# Robocrys condensation

Single and batch robocrys condensation plus combined-archive construction.

**Current package coverage:** A more robust implementation exists in `src/ssscreen/data/condense.py`.

**Historical cautions:** Historical workers swallow failures and contain fixed paths and worker counts.

Notebook outputs and execution state are preserved. External datasets and calculation artifacts referenced by these files are not included.
