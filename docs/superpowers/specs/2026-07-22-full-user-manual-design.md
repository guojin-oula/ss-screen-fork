# SS-Screen 完整功能版用户使用手册设计

## 1. 目标

为材料科研用户编写一套中文用户使用手册，说明如何从 Materials Project/WBM 原始材料数据出发，经过组成筛选、结构匹配、高精度带隙计算、固溶体端元配对、SQS、机器学习势驰豫、热力学与动力学稳定性、缺陷计算，最终形成带有证据和缺失数据说明的候选体系推荐报告。

交付物包括：

- `docs/user-guide/SS-Screen_完整功能版_用户使用手册.md`：可随代码持续维护的中文源稿；
- `docs/user-guide/SS-Screen_完整功能版_用户使用手册.docx`：适合审阅、打印和后续转换为 PDF 的正式文档。

本手册是“未来完整功能版”的产品使用说明与开发接口基线，不作为当前 `ss-screen 0.1.0` 已实现能力的证明。

## 2. 目标读者

主要读者是具备基本材料科学、晶体结构和电子结构计算背景的科研用户。手册假定用户能够：

- 在 Linux/WSL 或计算集群上使用命令行；
- 理解化学式、晶体结构、带隙、形成能和声子稳定性的基本概念；
- 根据所在机构环境配置 VASP、ABACUS、AiiDA、调度系统或机器学习势后端；
- 判断筛选结果是研究线索，而不是实验发现或最终热力学结论。

手册不以软件开发者或系统管理员为主要读者，但会给出足以复现科研计算的环境、后端、目录和错误恢复说明。

## 3. 文档定位与准确性边界

手册中的接口分为两类：

1. **当前可用接口**：命令、参数和文件格式以 `src/ssscreen/cli/app.py`、测试和当前 README 为准；
2. **完整版本预期接口**：为尚未实现的 DFT、MLP、声子、相图、缺陷与推荐模块定义目标命令和文件契约，统一使用“完整版本预期接口——当前代码尚未提供”标识。

任何章节都不得把预期接口表述为当前已经通过测试的功能。正式命令落地后，手册必须回到真实 CLI 和测试重新核对。

## 4. 组织方式

采用“端到端工作流为主、命令参考为辅”的结构。全书使用一套微型二元固溶体示例贯穿，使读者能够观察每一阶段如何读取上一步产物并生成下一步产物。

### 第一部分：认识软件

1. 软件概述；
2. 科学问题与适用范围；
3. 核心筛选原理；
4. 完整工作流和阶段状态图；
5. 当前功能与完整功能的差异。

### 第二部分：安装与配置

1. 硬件、操作系统和 Python 环境；
2. 核心安装与可选依赖；
3. WSL、Linux 工作站和集群使用方式；
4. Materials Project 凭据；
5. AiiDA、VASP、ABACUS、MLP 和声子后端；
6. 项目目录、缓存、日志和计算产物约定；
7. 安装验证和最小冒烟测试。

### 第三部分：完整科研工作流

1. 创建研究项目；
2. 读取并标准化 MP/WBM 数据；
3. 价态、元素、稳定性和组成模板初筛；
4. 生成并校验 robocrys 描述归档；
5. 局部环境匹配与同构原型分组；
6. 导出或托管高精度带隙计算；
7. 校验带隙结果并枚举固溶体端元对；
8. 生成不同组分的 SQS 合金结构；
9. 使用 MLP 驰豫端元和合金结构；
10. 计算混合焓；
11. 进行声子/动力学稳定性筛选；
12. 获取竞争相并进行相图比较；
13. 生成缺陷并计算空位形成能；
14. 汇总证据并生成候选推荐报告。

每一阶段固定包含：目的、前置条件、输入、命令、关键参数、输出、检查方法、失败恢复、结果解释、可复现性记录和下一阶段入口。

### 第四部分：结果解释与科研决策

1. 近零带隙端元和小直接带隙端元判据；
2. 结构同构与可形成固溶体之间的边界；
3. PBE、mBJ、HSE06 等方法差异；

5. 竞争相和缺陷结果的使用方式；

7. 缺失数据、失败计算和不确定性的展示；
8. 何时需要进一步 DFT 或实验验证。

### 第五部分：CLI 与文件契约参考

1. 命令总览；
2. 当前命令逐项参考；
3. 完整版本预期命令逐项参考；
4. CSV、JSON、JSONL、结构文件和 DataFrame 模式；
5. 退出码、日志、检查点与断点续算；
6. 后端与来源信息字段；
7. 目录命名和结果归档。

### 第六部分：附录

1. 完整示例；
2. 常见错误排查；
3. 参数默认值与推荐区间；
4. 术语表；
5. 第三方软件与许可证；

## 5. 完整功能数据流

```text
MP / WBM 数据
  -> 标准化数据集
  -> 价态与组成候选
  -> robocrys 描述归档
  -> 同构结构组
  -> 高精度带隙结果
  -> 固溶体端元对
  -> SQS 合金结构
  -> MLP 驰豫结果
  -> 混合焓曲线
  -> 声子稳定性摘要
  -> 相图与竞争相结果
  -> 缺陷形成能排名
  -> 综合推荐报告
```

所有阶段使用显式文件作为边界。昂贵计算允许由外部平台执行，但导出清单和回收结果必须遵守稳定模式，从而支持断点续算、方法比较和审计。

## 6. CLI 设计

### 6.1 当前可用命令

手册按真实实现记录：

- `ss-screen dataset mp`
- `ss-screen dataset wbm`
- `ss-screen valence-filter`
- `ss-screen composition-screen`
- `ss-screen condense`
- `ss-screen condense-index`
- `ss-screen condense-validate`
- `ss-screen structure-match`
- `ss-screen gap-export`
- `ss-screen gap-validate`
- `ss-screen pair`
- `ss-screen gap-compare`
- `ss-screen stability sqs-generate`
- `ss-screen group`（兼容入口）

### 6.2 完整版本预期命令

预期接口采用分组命令，避免顶层命令无限增长：

```text
ss-screen project init

ss-screen bands launch
ss-screen bands status
ss-screen bands collect

ss-screen stability relax
ss-screen stability mixing-enthalpy
ss-screen stability phonon-export
ss-screen stability phonon-collect
ss-screen stability phase-diagram

ss-screen defects generate
ss-screen defects launch
ss-screen defects collect
ss-screen defects rank

ss-screen recommend
ss-screen workflow run
ss-screen workflow status
```

`bands`、`phonon` 和 `defects` 均支持“导出/回收”和“AiiDA 托管”两种执行方式。两种方式产生相同的标准结果文件，后续阶段不与特定计算引擎绑定。

`workflow run` 只负责编排已经稳定的阶段命令，不隐藏中间文件；用户可以在任意阶段停止、检查、替换外部计算结果后继续。

## 8. 科研结果表达原则

- 软件输出是筛选证据，不宣称“发现”或“证明”材料能够稳定合成；
- 结构相似不等同于必然形成连续固溶体；
- 高精度带隙仍受泛函、SOC、弛豫、赝势和数值参数影响；
- MLP 能量用于初筛，不能自动替代一致设置下的 DFT 热力学验证；
- 虚频、竞争相和缺陷结果必须附带计算后端、版本、参数和失败状态；
- 推荐报告必须展示缺失证据，不得把未计算项当成通过。

## 9. Word 文档视觉设计

Word 版采用正式科研手册样式：

- A4 纵向页面；
- 中文正文使用等线或思源黑体，英文和代码使用等宽字体；
- 封面包含软件名称、版本、文档类型和日期；
- 三级标题体系、自动目录、页眉和页码；
- 命令使用独立代码块；
- 输入输出、参数和阶段状态使用统一表格；
- 关键警告和“当前/预期接口”使用不同提示框；
- 包含完整工作流图、阶段产物图和界面示意；当前接口可使用实际终端截图，预期接口只能使用明确标注的“交互示意图”，不得伪造运行成功截图；
- 生成后逐页渲染检查中文字体、分页、表格、代码换行和页眉页脚。

## 10. 验收标准

### 内容

- 覆盖从数据输入到最终推荐的完整科研流程；
- 当前命令与真实 CLI 一致；
- 每个预期命令都明确标注未实现状态；
- 每一阶段都说明输入、输出、检查、失败恢复和科研解释；
- 不包含秘密、真实凭据、私有绝对路径或大数据文件；
- 不把筛选信号表述为最终实验或热力学结论。

### Markdown

- 本地链接有效；
- 无 `TODO`、`TBD` 或未解释占位符；
- 命令、文件名和术语前后一致；
- 可作为 Word 版的权威内容源。

### Word

- 目录和标题层级清楚；
- 页面无文字截断、表格越界、乱码、孤立标题或大面积意外空白；
- 每页完成渲染和视觉检查；
- 与 Markdown 版核心内容一致。

## 11. 非目标

- 本次不实现手册中规划的未来 CLI；
- 不运行真实 DFT、AiiDA、MLP、声子或缺陷计算；
- 不打包完整 MP/WBM 数据集或历史计算目录；
- 不把未来完整功能版手册直接作为当前 `0.1.0` 的软著鉴别材料；
- 不修改现有算法阈值或科学判据。
